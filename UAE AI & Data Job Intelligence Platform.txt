# UAE AI & Data Job Intelligence Platform

![Project Logo Placeholder](docs/assets/logo.png)

## Overview

The **UAE AI & Data Job Intelligence Platform** is an open-source initiative designed to continuously collect, transform, and analyze job market data within the United Arab Emirates. Our primary goal is to provide actionable intelligence for a diverse range of data and AI professionals, including Data Analysts, BI Analysts, Data Engineers, Analytics Engineers, AI Engineers, and ML Engineers. The platform aims to answer critical questions about the UAE job market, such as identifying growing skills, understanding the salary impact of various technologies, pinpointing aggressive hiring companies, and outlining optimal learning paths.

This project is built with a strong emphasis on being **open-source first** and fostering **local-first development**. This means the entire stack can be run and managed effortlessly through Docker Compose. We envision this platform feeling like an internal labor market intelligence product at a large enterprise, delivering robust and insightful data without relying on expensive paid APIs.

## Features

Our platform boasts a comprehensive set of features:

*   **Data Ingestion:** We collect job market data from various online sources through Python-based API ingestion and ethically sound web scraping.
*   **Data Transformation:** We utilize `dbt Core` to meticulously clean, structure, and model raw data into refined analytical datasets.
*   **Orchestration:** `Prefect` is employed for robust scheduling, monitoring, and management of our intricate data pipelines.
*   **Backend API:** A high-performance `FastAPI` backend serves as the backbone for delivering data and AI-generated insights.
*   **Interactive Dashboard:** A `Streamlit` dashboard provides an intuitive and interactive interface for exploring and visualizing job market intelligence.
*   **AI-Powered Insights:** We leverage local Large Language Models (`Ollama` with `Qwen 3 8B` or `Gemma`) for advanced text analysis, precise skill extraction, and sophisticated trend prediction.
*   **Containerized Environment:** The entire technology stack runs seamlessly via `Docker Compose`, ensuring consistent and reproducible development and deployment across all environments.

## Getting Started

These instructions will guide you through setting up and running a copy of the project on your local machine for development and testing.

### Prerequisites

Before you begin, please ensure you have the following installed:

*   [Docker](https://docs.docker.com/get-docker/)
*   [Docker Compose](https://docs.docker.com/compose/install/)
*   [Git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Paddych96/uae-ai-data-job-intelligence.git
    cd uae-ai-data-job-intelligence
    ```

2.  **Start the environment:**
    The entire development environment, encompassing databases, Prefect server, FastAPI, Streamlit, and Ollama, can be brought up with a single command:
    ```bash
    docker compose up --build
    ```
    Please note that this command will build the necessary Docker images, start all services, and set up the initial database. It might take some time on the first run, particularly for downloading base images and LLM models.

3.  **Access the applications:**
    Once the services are up and running, you can access the various components:

    *   **Streamlit Dashboard:** Typically available at `http://localhost:8501`
    *   **FastAPI Backend (Swagger UI):** Typically available at `http://localhost:8000/docs`
    *   **Prefect UI:** Typically available at `http://localhost:4200`
